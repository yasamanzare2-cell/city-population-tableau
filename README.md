# City Population Analysis – Tableau

## Project Overview

This project analyses a global city population dataset using Tableau.

The aim was to explore population patterns across cities and countries and create clear, interactive visualisations.

## Dataset

The dataset contains information about cities, including:

- City name
- Country code
- District
- Local name
- Population

## Analysis

The Tableau dashboard includes:

- Top 10 cities by population
- Population by country
- Global city population map

## Key Skills Demonstrated

- Data preparation
- Data analysis
- Tableau
- Data visualisation
- Geographic mapping
- Dashboard creation
- Filtering and sorting

- Tableau Public
